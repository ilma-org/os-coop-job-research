\section{Use of Generative AI Platforms/Models}\label{sec:genai}

We used two Generative AI platforms: Claude Code (Anthropic) \cite{genai-claude-code-claude-opus-5-5,genai-claude-code-claude-opus-5-5-and-claude-sonnet-5-5,genai-claude-code-claude-sonnet-5-5} and Codex (OpenAI) \cite{genai-codex-gpt-6-1-sol}. We chose them because both are agent harnesses: tools that let a model read files, run scripts and search the web under rules that we wrote in the repository, so that the model does the right job at each step. One team member used Codex for their research topics, and the other members used Claude Code. Codex ran claim research and the blind author check only. Claude Code also ran the reviewer rechecks and drafted this report. The same rules applied to both platforms. We did not compare the quality of their output, and because different people used them on different topics, we cannot say which platform is better. Table~\ref{tab:genai} lists each platform and model, what we used it for, and how many prompt logs it produced. The complete record is \logsTotal{} prompt logs in our public project repository \cite{repo}; we marked \logsSignificant{} of them as significant, the ones that matter most for this report, and the Appendix shows the prompts we typed in them.

\paragraph{How we used GenAI.}
GenAI helped us read and organise sources. It did not decide what is true. Each factual statement in our knowledge base is a claim with a published source, an access date and an exact sentence copied from that source. A claim could pass through four steps:
\begin{enumerate}
  \item \textbf{Research.} An agent read published sources (mainly the Google SRE books and official documentation) and proposed claims with a quote.
  \item \textbf{Blind author check.} A fresh agent received only the claim text and the source address, never the stored quote, and said whether the source supports the claim.
  \item \textbf{Reviewer recheck.} A different team member ran the same blind check in a separate session.
  \item \textbf{Human review.} The reviewer opened every cited source. Only then did the claim become ``human-verified''.
\end{enumerate}
Of \claimsTotal{} claims in our knowledge base, \claimsHumanVerified{} passed all four steps and are human-verified. Another \claimsAiChecked{} passed the blind author check but not the human review. This report draws on both groups. A further \claimsAssumption{} are assumptions and recommendations. They have no source by design, are labelled as such, and can never become human-verified.

\paragraph{What we corrected.}
The checks changed the content. A reviewer recheck found that the phrase ``not a fixed limit'' went beyond what the SRE book page says, and we replaced the claim with one that stays inside the source. A recheck of 24 claims marked 10 as unreachable because the source site could not be opened, and we rechecked those 10 using archived and mirrored copies. After a review of one pull request, we dropped, reworded and retyped claims about server and database software. Reworded claims went through the blind check again; in one recheck, two of three claims were supported and one only partly.

\paragraph{Report creation.}
We also used GenAI to draft report text and to create the relationship diagram in Figure~\ref{fig:chain}. A fresh agent that had none of our context checked the report against the assignment requirements. The Appendix shows the prompts that we typed for this work. Claude Code wrote the instructions for the checking agent itself, and the logs do not hold them.
